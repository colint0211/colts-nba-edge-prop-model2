Model data and methodology
Checking data sources…
Team strength uses estimated offensive/defensive efficiency, net rating, pace, effective field-goal percentage and turnover rate. Offensive rebounds are approximated in the possession estimate. Situational features include rest, back-to-backs, travel, time-zone changes and elevation. Official injury reports are checked after initial candidate ranking. Games with questionable/doubtful rotation availability are withheld until that absence can be valued reliably. True EPM and reliable on/off ratings are not yet integrated. DraftKings lines are used to calculate market-relative edge and expected value; they are not used to create the model's projected score or probability. Historical player-prop results remain archived and are never blended into this record.
